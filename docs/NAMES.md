# Names used in Hull Down

Check this file and section 8 of `.github/LONGLIGHT-STUDIO.md` before adding
any name. Hull Down is its own world, separate from every other Longlight game.

**Do not use:** Kestrel, Kessel, Kessler, Harbourline, Hollis, Lantern,
Halyard, Sable, Ember, Kite, Harrow, Corvid, Tidewater, Northwind, Courier,
Ledger, Nimbus, Heron, any new country starting with V, or any Red Skies
aircraft or weapon name.

## Designation scheme

**Project numbers (PR 2c), Kelbo to confirm.** Every design the bureau starts
gets a project number, shown as `Project 101`. Numbers start at 101, go up by
one, and are never reused, even after a design is scrapped. The player gives
each design its own name (up to 28 characters); a design without one shows as
"Unnamed design".

Service designations (what the army calls a tank once it is adopted) are to
be written in PR 8.
