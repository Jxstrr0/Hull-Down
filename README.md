# Hull Down

A tank design game by Longlight Interactive.

You run a state tank design bureau in Tarnovia from the 1980s to today. The
army issues a requirement, you design a tank part by part against a weight
limit, and the prototype goes to trial. When it fails, the after-action report
shows why.

**Status:** early scaffold (0.1.0.0). There is nothing to play yet.

- Play: https://hulldown.longlight.games/
- Plan: [`docs/HULL-DOWN-PLAN.md`](docs/HULL-DOWN-PLAN.md)
- Progress: [`docs/STATUS.md`](docs/STATUS.md)

## Run it

```
npm install
npm run dev     # local server
npm run test    # tests
npm run lint    # lint and type check
npm run build   # production build into dist/
```

Everything in the game is fictional: countries, vehicles, makers and people.
